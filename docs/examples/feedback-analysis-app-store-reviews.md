# 示例：学习 App 用户反馈分析

## 使用场景

- 文档类型：用户反馈分析
- 使用 Skill：系统默认用户反馈分析 Skill
- 输出格式：问题归因与迭代建议
- 资料来源：应用商店评论、客服记录、问卷开放题

## 输入信息

```text
我们有一个学习类 App，最近用户评论里经常提到：

1. 课程收藏后找不到
2. 学习记录偶尔不同步
3. AI 答疑有时回答太泛
4. 会员页看不懂不同套餐区别
5. 部分用户希望能导出学习笔记

希望整理成产品经理能用的反馈分析，帮我判断优先级和下一步怎么验证。
```

## 输出节选

```markdown
# 学习 App 用户反馈分析

## 1. 反馈摘要

当前反馈主要集中在三类问题：

- 学习路径中断：收藏、学习记录、笔记导出影响用户持续学习。
- AI 价值感不足：AI 答疑回答泛化，导致用户不愿为 AI 功能付费。
- 付费决策阻力：会员套餐表达不清，影响转化。

## 2. 问题归类

| 问题 | 反馈类型 | 用户影响 | 初步优先级 |
|---|---|---|---|
| 课程收藏后找不到 | 信息架构 / 找回路径 | 用户无法继续学习 | P1 |
| 学习记录不同步 | 稳定性 / 数据一致性 | 破坏信任 | P0 |
| AI 答疑太泛 | AI 质量 / 内容相关性 | 降低付费意愿 | P1 |
| 套餐区别不清 | 商业化 / 转化路径 | 影响购买决策 | P1 |
| 导出学习笔记 | 效率工具 / 数据流转 | 提升长期价值 | P2 |

## 3. 根因假设

### 3.1 学习记录不同步

可能原因：

- 多端同步状态没有及时刷新。
- 离线或弱网场景下缺少清晰提示。
- 本地记录和服务端记录存在覆盖逻辑。

需要验证：

- 发生问题的平台、版本和网络环境。
- 是否集中在跨设备使用用户。
- 是否和特定课程类型有关。

### 3.2 AI 答疑太泛

可能原因：

- 用户问题缺少上下文，但系统没有追问。
- AI 没有结合当前课程、章节、错题和学习记录。
- 回答缺少例题、步骤和针对性解释。

## 4. 迭代建议

### P0：修复学习记录同步可信度

- 增加同步状态提示。
- 增加失败重试和冲突提示。
- 建立异常日志，定位版本、设备和课程维度。

### P1：优化 AI 答疑上下文

- 回答前读取当前课程、章节和最近错题。
- 用户问题不完整时先追问，不直接输出泛泛解释。
- 输出中增加“为什么错”和“下次怎么判断”。

### P1：重构会员套餐表达

- 用表格展示权益差异。
- 将 AI 答疑、笔记导出、课程数量等高频权益前置。
- 增加“适合谁”说明，降低选择成本。
```

## 为什么这个示例有价值

这个示例展示了 ProductGPT 不只是总结反馈，而是把反馈转成问题归类、根因假设、优先级和可执行迭代建议。
